# Customer Segmentation Analysis Using K-Means Clustering

## Project Overview
This project applies K-Means clustering to segment an e-commerce company's customers based on purchasing behaviour. Using Recency, Frequency, and Monetary (RFM) analysis, customers are grouped into distinct segments to support targeted marketing, improve customer retention, and identify valuable customers.

## Objectives
- Load, inspect, and clean the retail transaction dataset.
- Calculate customer purchasing statistics.
- Perform RFM analysis using Recency, Frequency, and Monetary values.
- Standardize features using StandardScaler.
- Determine the optimal number of clusters using the Elbow Method.
- Apply K-Means clustering to customer data.
- Visualize customer clusters using scatter plots.
- Profile customer segments using average RFM values.
- Compare the number of customers in each cluster.
- Recommend targeted marketing strategies for different customer segments.

## Project Workflow

### 1. Data Inspection and Cleaning
- Examined dataset dimensions, data types, missing values, and duplicates.
- Removed records without customer IDs or valid transaction details.
- Excluded invalid quantities, non-positive prices, and cancelled invoices.
- Calculated total transaction value.

### 2. Descriptive Statistical Analysis
Calculated customer-level statistics, including:
- Average purchase value.
- Purchase frequency.
- Total customer spending.
- Customer purchasing period.

### 3. RFM Analysis
Created three behavioural features:

- **Recency:** Days since the customer's most recent purchase.
- **Frequency:** Number of distinct purchases made by the customer.
- **Monetary:** Total amount spent by the customer during the observed period.

### 4. Feature Standardization
Applied StandardScaler to standardize the RFM features before clustering.

### 5. Optimal Cluster Selection
Used the Elbow Method to compare inertia values across different numbers of clusters and select a suitable value for K.

### 6. K-Means Clustering
Applied the K-Means algorithm to group customers with similar purchasing behaviour.

### 7. Cluster Visualization
Created scatter plots to visualize:
- Recency versus Frequency.
- Frequency versus Monetary value.

### 8. Customer Cluster Profiling
Calculated the customer count, average RFM values, total revenue, and percentage of customers in each cluster.

### 9. Customer Distribution
Created a bar chart showing the number of customers assigned to each cluster.

### 10. Marketing Recommendations
Developed marketing strategies based on the purchasing characteristics of each customer segment.
