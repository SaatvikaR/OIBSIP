# Task 1: House Price Prediction Using Linear Regression

## Project Overview
This project predicts house sale prices using Linear Regression and the Ames Housing dataset.

## Objectives
- Explore and analyze housing data.
- Handle missing values and encode categorical features.
- Train a Linear Regression model.
- Evaluate prediction performance.
- Compare Linear Regression with Ridge Regression.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
The dataset is from Kaggle's House Prices: Advanced Regression Techniques competition.

Dataset link: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques

## Methodology
1. Exploratory data analysis.
2. Feature selection and correlation analysis.
3. Missing-value handling and One-Hot Encoding.
4. An 80:20 training/testing split.
5. Linear Regression training and evaluation.
6. Actual-versus-predicted and residual plots.
7. Coefficient analysis and Ridge Regression comparison.

## Linear Regression Results
- MSE: 1,301,609,433.17
- RMSE: 36,077.82
- R² score: 0.8303 (83.03%)

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries: `pandas`, `numpy`, `matplotlib`, `seaborn`, and `scikit-learn`.
3. Download `train.csv` from Kaggle and place it in the notebook's working directory.
4. Open the notebook and run all cells in order.
