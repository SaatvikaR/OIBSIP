# Retail Sales Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, understand customer demographics, analyze product performance, and discover useful business insights.

## Objectives
- Load and inspect the retail sales dataset.
- Calculate mean, median, mode, and standard deviation.
- Analyze monthly and quarterly sales trends.
- Explore customer demographics by age group and gender.
- Identify the top 10 best-selling products or categories.
- Analyze revenue by product category.
- Visualize correlations between numerical variables.
- Compare average spending by age group and gender.
- Provide actionable business recommendations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
**Source:** Kaggle – Retail Sales Dataset

https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset

The dataset contains transaction dates, customer demographics, product categories, quantities, unit prices, and total transaction amounts.

## Project Workflow

### 1. Data Loading and Inspection
Examined the dataset's shape, column data types, missing values, duplicate records, and summary statistics.

### 2. Descriptive Statistics
Calculated mean, median, mode, and standard deviation for numerical variables.

### 3. Sales Trend Analysis
Created monthly and quarterly sales trend charts to examine changes in revenue over time.

### 4. Customer Demographics
Analyzed customer distributions by age group and gender using bar charts.

### 5. Product Analysis
Identified the best-selling products or categories and visualized revenue by product category.

### 6. Correlation Analysis
Created a correlation heatmap to examine relationships between numerical variables.

### 7. Additional Analysis
Compared average transaction spending across age groups and gender to explore customer purchasing patterns.

## Key Insights
The analysis helps identify:
- Monthly and quarterly sales patterns.
- Customer demographic distributions.
- Best-selling products or categories.
- Revenue contributions by product category.
- Relationships between numerical variables.
- Differences in average transaction spending across customer segments.

## Business Recommendations
1. **Inventory Management:** Maintain sufficient stock of popular products and categories.
2. **Targeted Marketing:** Design marketing campaigns for relevant customer segments.
3. **Sales Optimization:** Plan promotions during periods of lower sales.
4. **Revenue Growth:** Focus on product categories that contribute significantly to revenue.
5. **Customer Retention:** Introduce loyalty programs and personalized offers to improve customer engagement.

## How to Run the Project

### Install the Required Libraries
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Run the Notebook
1. Download the dataset from Kaggle.
2. Place the CSV file in the project directory.
3. Open a terminal in the project directory.
4. Run the following command:

```bash
jupyter notebook
```

5. Open the notebook and run all cells in order.
